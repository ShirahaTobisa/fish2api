计费口径

本面板的「语音合成」走网页会话(POST /api/web/tts),消耗账号的订阅套餐 credits;POST /api/tts 走官方 API key,消耗 API 积分。两者是独立的钱包,余额在仪表盘看。

token 怎么来

最稳的办法:「账号」页「更新 token」里有个书签按钮,拖到书签栏;用你平时的浏览器登录 fish.audio,在它页面上点一下书签,token 就自动发过来。

自动续期:token 没有过期时间,服务每 10 分钟向上游验证一次,失效了就按账号的「续期」方式重新登录:GitHub / Google 能在后台无头完成;邮箱密码要过 reCAPTCHA,基本会被拦。

手动:fish.audio 页面按 F12 → Application → Local Storage → 复制 token 的值,到「更新 token」粘贴。
